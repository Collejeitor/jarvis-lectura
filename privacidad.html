Política de privacidad de JARVIS lectura

Última actualización: 7 de noviembre de 2026.

Qué datos usa

JARVIS lectura accede, con el permiso expreso de su dueño y solo en modo lectura, a los mensajes de su bandeja de entrada de Gmail (gmail.readonly) y a los eventos de su calendario (calendar.readonly). No modifica, envía ni borra nada.

Qué hace con ellos

Los datos se leen y se procesan en el propio ordenador del dueño para mostrar un resumen del día. No se envían a ningún servidor, no se comparten, no se venden y no se usan para publicidad ni para entrenar modelos.

Cómo se guardan

La autorización (token de acceso) se guarda cifrada con la protección de datos de Windows (DPAPI), de modo que solo puede leerla el mismo usuario en el mismo equipo. La herramienta no tiene usuarios distintos del dueño.

Cómo revocar el acceso

El dueño puede retirar el permiso en cualquier momento en myaccount.google.com/permissions. Tras revocarlo, la herramienta deja de poder leer los datos.

Uso de datos de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Contacto

Consultas: github.com/Collejeitor/jarvis-lectura/issues.

English summary: JARVIS lectura reads the owner's own Gmail and Calendar data, read-only, on the owner's computer to produce a daily summary. Data is never sent to any server, shared, sold or used for advertising or model training. The access token is stored encrypted with Windows DPAPI. Access can be revoked at myaccount.google.com/permissions. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
